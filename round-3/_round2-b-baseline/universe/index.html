How a position is computed

  • Direction comes from the topic, chosen by rule from the title, stack and summary.
  • Distance from the centre is age: the newest work sits at “now”.
  • Size grows with the number of documented links and whether it has a write-up.
  • Height above the plane is a stable per-item offset so nothing overlaps. The automated Digest lies flat in the plane.
