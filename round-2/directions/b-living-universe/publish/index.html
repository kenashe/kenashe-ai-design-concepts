Prototype-only page · publishing demo

Publish something. Watch where it lands.

Each step adds one example entry in the exact format production already uses. The browser rebuilds the graph from those files, and the universe places the new body by itself: its topic sets the direction, its date sets the distance from now, and any link it contains becomes a thread. The entries are placeholders and are marked as such. Nothing is saved; reload to reset.

With JavaScript off, the steps below still show exactly what is typed and where. The live demo needs JavaScript.

What Ken types, and where

  1. 01

    Add a project

    Where src/data/builds.ts

    // src/data/builds.ts  (top of the projects array)
{
  title: 'Example project',
  status: 'LIVE',
  dek: 'A placeholder project added by the publishing demo.',
  stack: ['HyperAgent', 'AI Agents'],
  shippedAt: 'Nov 2026',
  link: '/building/example-project/',
},

    Effort One entry in builds.ts, plus a page file if the project gets a write-up.

    Today production also needs the title added to CURATED in building-cards.ts. Round 2 proposes replacing that list with an optional hidden: true flag in builds.ts, so a project is entered exactly once.

  2. 02

    Publish an article

    Where src/data/writing.ts + src/pages/writing/example-essay/index.astro

    // src/data/writing.ts  (top of the essays array)
{
  slug: 'example-essay',
  title: 'Example essay',
  date: 'November 25, 2026',
  published: '2026-11-25',
  dek: 'A placeholder essay added by the publishing demo.',
  authorship: 'Written by hand',
  image: { file: 'example-essay.jpg', alt: '…' },
},
// …and the page links to /building/example-project/, which becomes a relationship.

    Effort One metadata entry, the page itself, and one image file. Exactly the current workflow.

    Relationships are not entered anywhere. A link written in the essay is the relationship.

  3. 03

    Upload a video

    Where YouTube (no file to edit)

    <!-- YouTube channel feed, read at build time -->
<entry>
  <yt:videoId>EXAMPLEvid1</yt:videoId>
  <title>Example video</title>
  <published>2026-11-25T18:00:00+00:00</published>
  <media:description>… kenashe.ai/building/example-project/</media:description>
</entry>

    Effort Nothing on the site. The next build reads the channel feed. A kenashe.ai link in the description creates the relationship.

    The feed only lists the latest 15 uploads, so the build appends each one to source/youtube-archive.json and nothing falls off the site.
