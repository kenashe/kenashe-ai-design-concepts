Updating the site, demonstrated

Five ordinary updates, applied one after another to a separate copy of the site. After each one the site was rebuilt and compared with the build before it, so the lists below are measured, not described. The example entries exist only in this demonstration build; the review prototype contains none of them.

3 Publish a video on YouTube

What Ken does: Nothing on the website. The video sync reads the channel feed, adds the video to the archive and fetches its thumbnail.

node tools/sync-videos.mjs   (run here against an example feed with one new upload; YouTube’s image server is unreachable for the made-up video, so the title-card fallback shows)
